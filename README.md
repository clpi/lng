# lng

Written mainly in Makefile, C++, C.

## Contents

- `Makefile` — the build file
- `build.ninja` — a file
- `dist` — directory
- `scripts` — scripts
- `src` — source code

## Build and run

Build targets defined in the `Makefile`: `all`, `setup`, `list`, `build`, `build-llvm-bc`, `build-llvm-ll`, `view-llvm-asm`, `compile-llvm-asm`, `run`, `run-llvm`, `run-llvm-bc`.
